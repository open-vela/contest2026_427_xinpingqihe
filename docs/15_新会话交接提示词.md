### 蓝牙断点：已结案（2026-09-18；原判断"断点在 H4 传输层"只对了一半）

**真因不是"传输层配置"，而是"谁在写 fd"**：zblue 的 NuttX port 让 `h4_send()` 跑在
Zephyr 系统工作队列线程里，而 NuttX 的 fd 表按 **task_group** 存
（`fs/inode/fs_files.c` `file_get2 → nxsched_get_fdlist → tcb->group->tg_fdlist`），
该线程与 `h4_open()` 所在组不是同一个 ⇒ `write()` 恒返回 **EBADF(errno 9)**，
控制器一个字节都没收到。`-EIO(-5)` 是 `hci_core` 在 `bt_send` 失败后用
`hci_cmd_done(.. BT_HCI_ERR_UNSPECIFIED)` **伪造** status 0x1F 再翻译出来的**假象**。
**修法**：`port/drivers/bluetooth/hci/h4.c` 的 `h4_send()` 只入 `tx_fifo`，
真正的 `write()` 交给与 open 同组的 `h4_rx_thread`。

**已实测**（出货固件，同一 boot）：
```

[BTHCI] rx (7 B): 04 0e 04 06 03 0c 00        ← 阶段A裸探针 status=0
[bt] bt_enable rc=0 (host stack up) elapsed=1227ms
[bt] B2 gatt register rc=0 / conn cb register rc=0 / adv start rc=0
[bt] B2 READY name=PhyWear identity=CD:AB:78:56:34:12
[bt] SELFTEST PASS  (read 16B, |a|=1013 mg, write cmd ok)
```

`python3 tools/pw_bt_b3.py --out docs/evidence/bt-b3-$(date +%Y%m%d-%H%M) --wait 240`
（自动判 广播/连接/订阅/写入/无报错 五项）。
⚠️ 广播用**随机地址**（EXT_ADV+PRIVACY），**手机按名字 `PhyWear` 找，不能按 MAC**。

这一个 boot 的 GUI 额度就被它用掉了。判定器已加"等到 `adv start rc=0` 才算生效"的 5 次重试

## 6. 已踩过的坑（别重复）
- **CMake target 名猜错** → `Configuring incomplete`；正确名 `apps_phywear`。
- `grep -c "error"` 会把源码行 `LOG_E("LCDC error code %x")` 算成错误（25 个假阳性 → 白回滚一次）；必须用 `error:`。
- `lv_obj_move_background()` 会把元素压到**不透明底晕之下** → 界面零变化；靠 **sha256** 才发现（"没报错"≠"生效"）。
- 字体子集扫描器只认源码里的**原始 UTF-8 汉字**（`\uXXXX` 不算）；缺字优先**换文案**（零风险），再考虑重跑 `tools/phywear/gen_fonts.sh`。
- LVGL v9：`lv_obj_set_y` 只写样式、`lv_obj_get_y` 读已布局值（新建对象读到陈旧值）⇒ 动画终点必须显式传 base y。
- 抓帧：实时重绘页严格模式必失败；**`/dev/ttyUSB0` 掉线时烧录/串口会全部静默无输出** → 先 `ls /dev/ttyUSB0`。
- 提示符陷阱：`vela>` 是 ai_agent 的 CLI，那里 `phywear` **不是命令**；GUI/探针入口是 `phywear cap <page>` 与 `phywear bthci`。
- **行结束符是 `\n` 不是 `\r`**：发 `help\r` 只回显不执行（`pwshot.py` 能用是因为它发 `\r\n`）。
- **`vela>` 与 NSH 抢同一个 stdin**：谁先阻塞在 read 谁拿到那行；开机 ~30 s 后 netmgr 超时会把控制台放开，之后 NSH 通常赢。
- 改 defconfig 后必须 `cmake --build <dir> --target resetconfig`；**别手改 `cmake_out/.../.config`**（会带坏 configure）。
- GATT 回调 / 周期通知都跑在 **Zephyr 系统工作队列线程**（栈 4096 B）上；任何在里面做的阻塞工作（比如读传感器现采）都要**限时**，否则会堵住 HCI 命令 TX 与收包处理。
