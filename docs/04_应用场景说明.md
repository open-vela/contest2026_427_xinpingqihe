# 04 应用场景说明

> 大赛必做项：**交付应用场景说明**（用户故事 / 功能清单 / 技术实现用了 ai_agent 哪些核心能力）。
> 本文同时给出端侧/云侧任务拆分与现状边界，全部按**实际交付状态**书写。

---

## 1. 一句话定位

**把一块带 6 轴 IMU、磁力计、环境光、麦克风和喇叭的智能手表，变成学生随身携带的物理实验台**，
再用 openvela 官方 `ai_agent` 当"实验助教"：学生说一句话，手表切到对应实验页、开始采样，
Agent 用测得的数据讲物理；喇叭与麦克风让"发声—拾音"这条链路在手表上可做（发正弦 → 麦克风电平/频谱页看读数；受小喇叭声压与同板耦合限制，见 §8 边界）。

---

## 2. 目标用户与场景

| 用户 | 场景 | PhyWear 提供什么 |
|---|---|---|
| 初中/高中学生 | 课后做「单摆测 g」「弹簧振子」「向心力」等课本实验 | 16 个实验/测量页面 + 实时曲线，不需要实验室器材 |
| 物理老师 | 课堂演示加速度、频谱、倾角、声音 | AMOLED 实时曲线可投影；一句话切页 |
| 科普/家长 | 想知道"手表怎么知道我抬手" | 原始传感器 6 页（含麦克风电平、扬声器发声）看得见传感器在干什么 |
| 不便操作屏幕的用户（规划） | 不想一层层点菜单 | 语音/文字直接说"打开单摆实验"；后续做无障碍播报 |

痛点：手机做实验要掏出来、解锁、装 App；实验器材要预约。**手表抬手就有。**

## 3. 用户故事

### S1 直接开实验（对话式操作）
> 用户：「帮我测一下重力加速度」
> Agent：`list_experiments` → `open_screen(pendulum)` → `run_experiment(10s)`
> Agent：「已切到单摆页并采样 10 s，周期约 1.42 s，按 L=0.50 m 算得 g ≈ 9.7 m/s²，与 9.8 差 1%，结果可信。」

### S2「这数是什么意思」（把数据讲成物理）
> 用户：「现在这个频谱图是什么？」
> Agent：读页面上下文 → 解释主频对应的物理量，提示摆幅过大会让主频偏移。

### S3 声学通路：发一段正弦，看麦克风读到什么
> 用户：声学 → 音频发生器 → 播放 440 Hz；切到原始传感器—麦克风页
> 手表：喇叭发正弦，麦克风拾音，界面显示 **-34 dBFS 与 32 段电平柱**；用 −/+ 改频率音量，电平随之变化。
> （真机实测：喇叭放 1 kHz 时麦克风峰值 **12000 LSB ≈ -8.4 dBFS**；静音基线约 570 LSB）

### S4 用已知频率校准麦克风频谱 / 找共振
> 用户在音频发生器扫频（220→1760 Hz 预设或 20 Hz 步进），在麦克风频谱页观察峰值位置：
> 既能验证频谱轴是否准确，也能找房间/表壳共振点。

### S5 一次性说明页（教学辅助）
> 每个实验页都有"帮助"说明（原理、公式、操作步骤、误差来源），课堂上可直接当讲义翻。

## 4. 功能清单

**手表端（C + LVGL 9.1，真机已跑通）**

| 域 | 内容 |
|---|---|
| 原始传感器（6 页） | 加速度 / 陀螺仪 / 磁力计 / 环境光 / **麦克风电平** / **扬声器** |
| 力学实验 | 单摆测 g、弹簧振子、向心力 |
| 声学 | 麦克风频谱（FFT）、**音频发生器（喇叭发正弦 40 Hz–4 kHz）** |
| 工具 | 加速度频谱、磁场频谱、倾角、磁性标尺 |
| 计时器 | 运动秒表、光学快门、声学快门、掌声计 |
| 系统 | 设置（中英切换）、关于、根菜单 |
| 平台能力 | 中英双语 + CJK 字体子集；真机串口截图能力；41 FPS（render 22 / flush 0） |

**Agent 端（官方 ai_agent，真机已跑通）**

- 4 个工具：`phywear_list_experiments` / `open_screen` / `read_sensor` / `run_experiment`
- 1 个自定义 Markdown Skill：`phywear-physics-coach.md`（实验流程 + 物理关系 + 边界条件）
- 离线意图表：无 LLM / 断网时按关键词直接执行工具
- 开机自动把 Skill 装到 `/data/agent/skills/`（真机 `/data` 是 tmpfs）

## 6. 端云任务拆分

| 环节 | 端侧（手表） | 云侧（LLM） |
|---|---|---|
| 传感器采样 | ✅ 50 Hz 采样、滤波、峰值/周期提取（`pw_analysis.c`） | — |
| 界面与实时曲线 | ✅ LVGL + EPIC 硬件加速 | — |
| 事件判定 | ✅ 摆动检测、电平/频谱计算 | — |
| 意图路由 | ✅ 命中离线意图表 → 直接调工具 | 未命中 → 交给 LLM 规划 |
| 实验流程编排 | ✅ 工具执行（切页 / 采样） | ✅ LLM 决定先列页面再开页面、采样多久 |
| 物理讲解 | 兜底文案（离线） | ✅ 把数据讲成物理、对比理论值、追问 |
| 长时记忆 | ✅ 本地文件（`/data/agent/memory/`） | — |
| 联网检索 | — | ✅ 需要时用搜索工具（如查当地重力加速度） |

**降级策略**：断网/无 Key → 端侧意图表 + 本地记忆，能力降级但不罢工。
**当前真机没有网络栈**，所以：真机演示走端侧路径；LLM 对话与云侧能力在 goldfish 模拟器演示。

## 8. 现状与边界（如实）

1. **真机无 WiFi**：BLE 已打通 GATT、PPP over BLE 已到 IP 层（`docs/14/16`）；但 **LLM 对话仍在模拟器演示**（真机端 LLM 未联调），真机走端侧意图表 + 工具。
2. **真机未配 LLM Key**；`/data` 是 tmpfs（Skill 每次开机由 PhyWear 安装）。
3. **模拟器没有真实传感器**：`CONFIG_EXAMPLES_PHYWEAR_SIM` 下 IMU 为合成波形，仅用于链路验证，**不得作为测量结果引用**。
4. **"主动+执行"场景已交付并默认开启**（2026-09-15）：晃表 → Agent 自动打开单摆实验 → 测得 g → 结果进手表 AI 日志，真机已验证（`docs/evidence/proactive-20260915/`）。曾经卡死的真因是 Agent 侧自己 50 Hz 采 IMU 与页面抢 I2C，现已改成「开页 → 等结果 → 读结果」。**残余**：静止/振动桌面下单摆页仍可能给出无效 g（三道有效性门有漏过）。后续方向：无障碍播报、首次开机语音引导、结果语音播报（见 `05_AI_Agent与Skill.md` §5）。
5. 真机已知限制：`Ctrl-C` 杀不掉 `phywear`；同一 boot 内第二个 GUI 实例会挂；两次运行之间需复位。
