## 6. FlashTable（ftab）说明

- 出厂板 flash 起始 `0x12000000` 是空的：SiFli ROM 必须先读到 ftab 才知道二级 bootloader 的 base/size/**xip_base**。
- 修复：把 bootloader 条目的 `xip_base` 从 `0x20020000`（拷到 RAM）改成 **`0x12010000`**（原地 XIP），以匹配 openvela 链接脚本 `flash ORIGIN = 0x12010000`。
- 烧录顺序不能反：**先 ftab（`@0x12000000`）再固件（`@0x12010000`）**，脚本 `~/openvela/flash_with_ftab.sh` 已封装。
- ⚠️ sftool 的读回校验会**偶发报"不一致"**（工具/ROM 侧抖动）：复核办法是分块（≤16 KB）重读比对，或看启动日志；**禁止 `erase_flash`**。

## 7. 已知限制（如实）

1. **真机无网络栈**（无 WiFi/BLE 协议栈入镜像、无网卡驱动）→ LLM 对话与云端能力在 **goldfish 模拟器**演示；真机走端侧离线意图表。
2. **真机未配 LLM Key**（`set_llm` 未配置）；`/data` 是 tmpfs，重启即空。
3. 模拟器**没有真实传感器**：`CONFIG_EXAMPLES_PHYWEAR_SIM` 下 IMU 为合成波形（摆动检测/图表链路验证用），**不得作为测量结果引用**。
4. `Ctrl-C` 杀不掉 `phywear`（未开 `CONFIG_TTY_SIGINT`）→ 只能复位。
5. 同一 boot 内**第二个 GUI 实例**会挂在 LCD 驱动 → 两次运行之间必须复位。
6. 主动场景（摆动 → Agent）当前**默认关闭**，原因与后续方向见 [`05_AI_Agent与Skill.md`](05_AI_Agent与Skill.md)。
7. `WARN: fps probe: open /dev/fb0 failed` —— 本板级配置走 `lcd0`，无 `fb0`，FPS 探针不可用（不影响功能）。
