## 二、摘要（模板第 2 节，≤300 字，量化）

本项目在立创黄山派（SF32LB52-MOD-1）上开发腕上智慧物理工坊 PhyWear。
本队独立完成：**3 个新 NuttX 传感器驱动**（MMC5603 地磁 / LTR-303 环境光 / 麦克风 DMA，**1,505 行**，

（**32 文件 10,808 行**，15 个实验/工具/页面）；自研 FFT/自相关/曲线控件库（**1,600 行**）；
EN/ZH 双表 **388 条** + 5 档 CJK 字体。
在**官方 EPIC 硬件加速**（PR #31/#41/#121，**非本队自研**）基础上做 UI/算法层优化，**真机渲染
3 → 43 FPS（×14）**，模拟器 22–23 FPS。摆测 g 实测误差约 1.8%，算法端侧、不依赖手机。

以 C+LVGL 独立重实现。AI 主动交互为规划中、未实现。

## 三、正文（模板第 3 节）

### 3.1 绪论
- **背景与问题**：物理实验（phyphox）需手机手持；腕上可穿戴让实验时"腾不出手"的场景（跑步、
  骑车、实验操作）也能实时看加速度频谱/摆测 g 等。
- **技术难点**：在黄山派 SF32LB52 上进行**新传感器驱动开发**（MMC5603 地磁 / LTR-303 环境光 /
  麦克风 DMA）与板级 bringup、在官方 EPIC 显示栈上修复触控、嵌入式端侧物理算法（FFT/自相关/
  最小二乘）在 Cortex-M33 单精度 FPU 上实时算、UI/算法层优化使渲染性能
  从 3 FPS 提升到 43 FPS（真机，基于官方 EPIC + 本队 UI 优化；模拟器经 UI 层优化 22–23 FPS）。
- **创新点**：腕上形态 + 全中文界面 + phyphox 算法对齐 + LVGL 原生应用 + UI/算法层优化（EPIC 加速为官方提供，非本队自研）。

### 3.2 系统方案设计
- **总体架构**：openvela(NuttX) + SF32LB52 BSP + 传感器字符设备驱动（/dev/mag0、/dev/light0、
  /dev/mic0）+ LVGL 应用层（pw_graph/pw_scope/pw_analysis）+ EPIC 显示后端。系统框图见
  `docs/project/phywear_ui.md` 与 `phywear_optimizations.md`。
- **选型**：黄山派 SF32LB52 板载六轴 IMU、三轴地磁、环境光、麦克风，获 openvela 官方支持，
  超低功耗适合可穿戴；**全部算法端侧，无端/云划分、无断网降级**（纯端侧，不依赖手机）。
- **关键模块**：传感器读取接口 `pw_sensors_read_imu/mag/light`、物理算法库 `pw_analysis`
  （FFT/自相关）、图表库 `pw_graph/pw_scope`、实验页 `pw_*_screen()`。

### 3.3 核心算法与技术原理
- **AI 算法实现**：**本项目 AI 算法未实现**（AI 主动交互/端侧模型/云端模型均未做）；如后期补，
  拟基于 openvela ai_agent 做运动识别。**此处如实标注为规划中**。
- **关键机制**：自相关测周期（摆测 g、弹簧）、向心加速度 a-ω² 最小二乘、radix-2 FFT 频谱。
- **openvela 系统能力运用**：落地**图形**（LVGL + 官方 EPIC 硬件加速，真机 3→43 FPS）；`draw/sifli`
  EPIC 后端为**官方 PR #41 提供（非本队自研）**，本队做集成与 UI/算法层优化；**AI/多媒体未落地**。

### 3.4 系统实现
- **软件/固件架构**：NuttX 字符设备驱动 + LVGL 原生应用，子命令（phywear pendulum/spring/
  centripetal）串口输出实验结论。
- **硬件适配（是）**：芯片 SF32LB52（立创黄山派 SF32LB52-MOD-1）。**本队原创驱动**：MMC5603
  （地磁）、LTR-303（环境光）、模拟麦克风（DMA）——已提 **nuttx PR #378**；并在官方 EPIC 显示栈上
  修复 FT6146 触控。适配难点：两板 I2C 注册、DMA 采集、触控与 EPIC 栈共存。
- **⚠️ 归属声明（重要）**：**EPIC 硬件加速（LCD/FB 驱动、HAL、DMA 拷贝、LVGL EPIC draw unit）来自
  官方 PR**（vendor_sifli #31 / lvgl #41 / nuttx-apps #121），**非本队自研**；本队负责**集成使用**
  与其上的 UI/算法层优化。详见 `src/vendor/sifli/.../lckfb_huangshan_pi`、`src/nuttx/drivers/sensors/`。
- **应用/交互端**：LVGL 全中文 UI，操作路径 ≤3 步，大字体卡片。**AI 主动交互未实现**。
- **自定义 Skill**：**已沉淀 1 个**——`phywear-sf32lb52-devloop`（`.claude/skills/`），触发词+
  操作步骤+输出规范（编译→烧录→运行→截图→bench）。符合硬性要求。

### 3.5 系统测试与结果分析（务必量化）
- **测试环境**：模拟器（goldfish-phywear）+ 真机（黄山派，sftool 烧录 + UART 串口）。
- **功能测试**：各实验页可打开并显示（中文界面）；真机摆测 g 误差约 1.8%。
- **性能测试**：**真机** LVGL + 官方 EPIC + 本队 UI 优化 → 全场景平均 **43 FPS**（flush 0ms），优化前约 3 FPS；模拟器（无 EPIC）经 UI 优化 22–23 FPS；`fps_timeline.png`
  时序图 + `phywear_optimizations.md` 数据。
- **可靠性与稳定性**：FPS/空闲堆 bench 统计（`pendbench` 等）；SFBL 部分场景反复重启——经验证为
  **电源/板级原因，与代码无关**（有对照实验）。**注：本作非安全/健康类，无识别准确率/误报要求**。

- **成果总结（量化，本队原创）**：
  - **传感器驱动**：MMC5603 地磁 / LTR-303 环境光 / 麦克风（DMA）3 个 NuttX 驱动 + 两板 bringup，
    **1,505 行**（已提 nuttx PR #378）。
  - **应用**：PhyWear 全中文 LVGL 物理工坊，**32 文件 10,808 行**，15 个实验/工具/页面。
  - **算法/图表库**：自研 radix-2 FFT、自相关测周期、向心最小二乘 + `pw_graph`/`pw_scope`，**1,600 行**。
  - **性能**：在官方 EPIC 基础上做 UI/算法层优化，**真机 3 → 43 FPS（×14）**，模拟器 22–23 FPS。
  - **国际化**：EN/ZH 双表 **388 条** + 5 档 CJK 字体（14–28px）。
  - **验证**：真机摆测 g 误差 **1.8%**；中文界面截图 + FPS 时序证据。
