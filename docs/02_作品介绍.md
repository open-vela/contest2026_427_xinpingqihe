## 一、一句话介绍

**PhyWear 把手机端 phyphox 的物理实验搬到腕上**：在立创·黄山派 SF32LB52 上完成
openvela 平台适配（新传感器驱动 + 板级 bringup + 触控修复 + 官方 EPIC 硬件加速集成），
并叠加一个全中文、可实时采集 IMU / 地磁 / 环境光 / 麦克风、且**能自己发声**的
**LVGL 腕上物理工坊**应用。

> **灵感来源（如实声明）**：实验玩法与部分分析算法流程（自相关测周期、向心 a–ω² 最小二乘、
> 频谱 FFT）源自 **phyphox**（RWTH Aachen 开源手机物理实验工具，GPL v3）；本作用 **C + LVGL
> 独立重实现**（未复制其 Android/Kotlin 代码体），源码 Apache-2.0，已在 `app/phywear/NOTICE.md`
> 标注致谢。

## 三、技术难度（对标 30 分）

**难点一：在只有 512 KB SRAM 的 MCU 上把"实验室"塞进手表。**
从传感器到 UI 全链路端侧完成：自研 MMC5603 地磁（含 auto-SR 修复）、LTR-303 环境光、
模拟 MEMS 麦克风（AUDCODEC ADC + DMA）三个 NuttX 字符设备驱动；两颗板子的 I2C 注册差异；
以及在官方 EPIC 显示栈上恢复 FT6146 触控。今日又打通**片内 AUDCODEC DAC0 + 外部功放**
的扬声器通路（DMA 常驻循环、PA42 使能、ioctl 控制频率/音量）。

**难点二：Cortex-M33 上的实时物理算法。**
radix-2 FFT、自相关测周期、向心加速度最小二乘拟合，全部在端侧实时跑并驱动 390×450 AMOLED
上的自绘曲线（自研 `pw_graph` / `pw_scope`）。

**难点三：性能工程与平台稳定性。**
- 渲染：在**官方 EPIC 硬件加速（PR #31/#41/#121，非本队自研）**基础上做 UI/算法层优化
  （弃用 `lv_chart`，自研控件走 EPIC IMAGE blit），**真机 3 → 41 FPS**（当前固件；
  2026-09-12 旧固件记录为 43 FPS），render 22 ms / flush 0 ms；同一优化让**无 EPIC 的模拟器**
  从"很卡"到 22–23 FPS。
- 平台：定位并修复**启动期时钟/晶振建立时序竞争**（镜像微变即随机卡死，只打印 `AB`/`ABCD`），
  在 XTAL32 起振、DLL1 锁定、DLL2 锁定、PSRAM 1.8V LDO 四处补建立时间后，**连续 5/5、6/6
  复位启动正常**。定位手段是逐段 `arm_lowputc` 插桩——这个过程本身也是本作"能啃底层"的体现。

**难点四：声学通路（今日）。** 扬声器与麦克风都跑在片内 AUDCODEC 上，实现时踩到两个硬问题：
① 麦克风增益需从 0 提到 **+30 dB** 才可用；② **DAC 与 ADC 同时工作会卡死**（频谱页跑几分钟被看门狗复位），
改为互斥后 7 分钟泡机 14 次心跳 0 复位。喇叭放 1 kHz 正弦时麦克风峰值最高 12,000 LSB（−8.4 dBFS），
形成"发声 → 采集 → 显示（dBFS + 32 段电平柱）"的完整声学链路。

## 四、产品创新性（对标 20 分）

- **形态创新**：把 phyphox 从"手机拿在手上"变成"腕上随身"——跑步、骑车、单手持物做实验时，
  抬腕即可看加速度频谱、单摆测 g、弹簧、向心等实时结果。
- **教学场景创新**：腕上实验台 + 会讲物理的 AI 助教（Skill：`phywear-physics-coach.md` 教模型
  "先列页面再开页面、用 g=4π²L/T² 校验结果、说明边界条件"）。
- **声学自测创新（今日）**：设备自带扬声器 + 麦克风，可做单机声学实验（发已知频率 → 看自己的
  频谱/电平），无需外部器材。
- **差异化**：全中文界面（**267 条**双语文案 + 5 档 CJK 字体子集）+ phyphox 算法对齐 + 端侧不依赖手机。
- ⚠️ **如实说明**：AI 的"主动能力"目前是**工具调用 + 离线意图 + 定时/事件触发**，语音交互与
  端侧运动识别**未实现**。主动场景**已交付**：检测与执行都在端侧（离线意图 + 工具调用）完成；
  但**静止/振动桌面上单摆页仍可能给出无效 g** —— 我们加了「独立数据 + 可复现 + 合理性」三道门，
  残余漏过如实记录（约 1 条/70 s），根治需改页面的运动判据。

## 五、项目完整度（对标 20 分）

- **真机可跑**：固件 **2.08 MB**（flash 12.42%、SRAM **93.95%**），板载 **16 个主页面**（截图巡检口径）+ 原始传感器 6 子页 + **水平仪/标定 4 子页**（当前经无头入口 `cap imu*` 进入，主页 tile 待板块落位）；
  烧录脚本 `flash_with_ftab.sh`（含 ftab 修复与读回校验）、UART 1 Mbaud 控制台。
- **证据齐**：真机截图 26 张（主页面/说明页）+ 声学 3 张 + 串口日志 + 实测数字（g 误差 1.8%、
  声学通路实测（含弱耦合的如实说明）、启动 5/5、泡机心跳连续）——全部落在 `docs/evidence/`。
- **工程化**：i18n 双表 **267** 条 + 字体子集可脚本重生成；自研算法/图表库 **3,513 行**（FFT/自相关/图表/迷你曲线 + Mahony 姿态解算 + 六面法/磁椭球标定）；
  FPS/空闲堆 bench；开发流程沉淀为 2 个自建 Skill；git 打 tag 保证可回退。
- **可复现**：一键烧录脚本 + 真机截图工具（`tools/phywear/pwshot.py`）+ 模拟器配置。

- **产品路径**：腕上物理实验工具 → 教育硬件套件（实验指导 + 数据记录）→ AI 助教（规划中）。

## 八、展示效果（对标 10 分）与演示流程建议

**最抓人的三个镜头**：① 抬腕看实时加速度频谱/曲线；② 音频发生器滑到 880 Hz，麦克风页电平柱
瞬间抬起（**设备自己发声、自己听见**）；③ 真机截图工具把腕上界面"搬"到评委屏幕上。

| 档位 | 建议内容 |
|---|---|
| **30 秒** | 主菜单 →「声学」→ 音频发生器放 440 Hz → 切到麦克风页看 dBFS 与电平柱抬起 → 字幕给出「真机、端侧、无手机」 |
| **2 分钟** | ① 抬腕展示主菜单与 6 页原始传感器（含量级数字）；② 做一个真实测量：单摆测 g（给误差 1.8%）；③ 声学 30 秒版（音频发生器发正弦 + 麦克风电平页看读数）；④ **主动场景**：晃表 3 秒 → Agent 自动开单摆页并报出 g；⑤ 收尾：真机 41 FPS、启动 5/5 稳定 |
| **5 分钟** | 在 2 分钟基础上补：⑥ 平台适配工作（3 个自研驱动 + 扬声器通路 + 触控修复，用 `/dev` 节点与源码截图讲解）；⑦ EPIC 归属说明（官方 PR #31/#41/#121 + 本队 UI 优化，展示 3→41 FPS 时间线图）；⑧ AI 开发说明（Skill + 日志 + 离线意图表）；⑨ **惯性标尺**：姿态解算与六面/磁标定演示（含注入自测 `imubench`）；⑩ 已知限制（语音交互未做、蓝牙 no-go、③ 精度无转台真值、单摆页运动判据待改） |

> 拍摄提示：屏幕内容用**板载截图能力**（`phywear --shot/<page>` + `pwshot.py`）导出真实帧，
> 避免手机拍屏反光；串口日志与界面同屏录一段，可信度更高。

## 九、已知限制（一句话带过，逐条见事实清单）

真机无网络栈（LLM 对话在模拟器验证）；**主动场景已交付并真机验证**（晃表 → 自动跑单摆实验 → 结果上手表），
但静止/振动桌面下单摆页仍可能给出无效 g（三道有效性门有残余漏过，根治需改页面运动判据）；
**蓝牙经时间盒探针判定 no-go**（断在构建接线与 SRAM，见 `docs/evidence/bt-probe-20260915/`）；
**③ 姿态精度尚无转台真值**（目前只有「与加速度计独立解算一致 ~0.5°」这一间接证据）；
语音交互、端侧运动识别、频率追踪/多普勒/声呐、弹性碰撞、实验构建器、传感器日志导出均**未实现**；
演示视频待录（脚本 v4 与分镜表已就绪）。**所有未完成项均如实标注，不冒充跑通。**
