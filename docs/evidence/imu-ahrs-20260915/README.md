# ③ 惯性标尺 / 位置标定 —— 第一批（姿态与标定数学核心，2026-09-15）

> 本目录对应六项计划的第 4 项（③）的**代码核心**：姿态解算（AHRS）与标定数学。
> UI 板块归属（生活 / 工具）与真值测量参与方式**仍待用户拍板**，因此本批只交付
> 与 UI 无关、可独立验证的部分：两个纯算法库 + 真机可跑的无头入口 + 主机单测。

---

## 1. 本批交付了什么

| 文件 | 内容 | 依赖 |
|---|---|---|
| `apps/examples/phywear/pw_ahrs.{c,h}` | **Mahony 显式互补滤波（MARG 9 轴）**：四元数姿态 + 陀螺零偏估计 + 欧拉角输出；状态仅 76 B | 无（纯 C，无 NuttX/LVGL/动态内存） |
| `apps/examples/phywear/pw_calib.{c,h}` | **标定数学**：一维/二维最小二乘、**六面法**加速度标定、**磁椭球**（硬铁+软铁）、**陀螺静态零偏**（含"够不够静"判据） | 同上 |
| `phywear ahrs [秒]` / `phywear calib` | 真机/模拟器**无头**入口：先跑自检，`ahrs <秒>` 再跑实时姿态读数（oneshot 读 IMU + **真实 dt** + 加速度计倾角交叉校验） | 需传感器 |
| `tools/phywear/hosttest_math.sh` + `pw_math_hosttest.c` | **主机单测**：PC 上 <2s 跑完两个库的自检（改算法不必烧板子） | 只要 gcc |

**设计要点 —— 全部用流式充分统计，不保存原始样本**：磁椭球只存一个 9×9 正规方程（90 float
= 360 B），六面法只存 6 组累加，二维拟合只存一个 3×3；因此标定过程的 SRAM 占用**与采样点数无关**，
跑几小时也不涨。两个库自身**没有任何静态数据**，链接期 SRAM 增量 ≈ 0（只占 flash）。

## 2. 验证结果（三层，全部可复现）

### 2.1 主机单测（PC，最快）

```
$ bash tools/phywear/hosttest_math.sh
pw_ahrs_selftest  rc=0  max_attitude_err=0.881 deg   OK
pw_calib_selftest rc=0  worst_rel_err=0.0628            OK
ALL OK
```

### 2.2 模拟器（ARM64 目标，确认没有软浮点之类问题）

```
calib selftest: rc=0 worst_rel_err=0.0628
ahrs selftest: rc=0 max_attitude_err=0.879 deg
ahrs done: 300 samples, 0 with mag        ← 模拟器没有 /dev/mag0，自动退化为 6 轴
```

### 2.3 真机（立创黄山派 SF32LB52；板上固件 md5 `ac1d5c699d7724409549ad91d650aff0`，2,076,244 B —— 注：固件非可重现构建，md5 每次重编都会变）

```
phywear calib        → calib selftest: rc=0 worst_rel_err=0.0628
phywear ahrs         → ahrs selftest: rc=0 max_attitude_err=0.879 deg
phywear ahrs 20      → 1000 samples, 1000 with mag（50 Hz）
ahrs t= 19.8s mag=on  roll=+178.12 pitch= +23.63 yaw= +75.63
                     | accel-tilt r=+178.74 p= +21.94      ← 独立交叉校验，差 ~0.5°
                     | bias(dps)=+0.914 -0.920 -0.393
```

三个**真机**结论：

1. **姿态与加速度计独立解算一致**：静止时 AHRS 的 roll/pitch 与 `atan2` 直接由加速度计
   解算的倾角相差 **~0.5°**（roll 178.1 vs 178.7、pitch 23.6 vs 21.9）—— 两条完全不同的
   路径给出同一个答案，说明坐标约定与滤波实现没错。
2. **磁修正真的在工作**：mag 关掉时 yaw 以 ~2°/s 单向漂（陀螺 Y 零偏被估成 −2.18 dps，
   与漂移率吻合）；打开 mag 后 **yaw 稳定在 75.6° 不再漂**（10/10 条采样一致）。
3. **真实 dt 生效**：50 Hz 采样由 `CLOCK_MONOTONIC` 前后差算出，不依赖固定 20 ms 标称值
   （这是 docs/03 §4.8 明确要求的，参考包那份代码就是栽在固定 dt 上）。

## 3. 合成数据自检到底验了什么（以及没验什么）

自检分四段，**阈值都按实测留余量**，并且把"没验到"的部分写清楚：

| 段 | 内容 | 实测 | 判据 |
|---|---|---|---|
| A | 从错误初值静置收敛（无零偏无噪声） | **0.88°** | < 2° |
| B1 | **未标定**的 0.5~0.7 dps 零偏直接喂进去 | ~11° | < 20° |
| B2 | **先静止标定零偏再扣掉**（推荐流程） | ~1° | < 2° |
| C | 一维拟合 `y=2.5x−3` 还原 | 相对误差 6e-8 | rms < 0.5 |
| D | 六面法还原已知零偏/刻度 | 零偏误差 <1e-3 g、刻度 <1e-3 | resid<0.01 g、串扰<0.001 g |
| E | 磁椭球还原已知硬铁/软铁 | **球心误差 0.00 mG、校正后模长离散 0.000%** | 离散 < 5% |
| F | 陀螺静态零偏；"手抖"必须被拒 | 还原准确；±2.9 dps 抖动被判 −2 | — |

**没验的**（如实写）：
- **精度指标**（如"静态 pitch/roll ≤0.5°"）只在真机静止时用"与加速度计一致"间接看过，
  没有转台真值，**不构成精度结论**；
- 磁椭球拟合有个**固有性质**：软铁矩阵只能定到"一个未知旋转"（`A` 与 `A·R` 给出同一个二次型），
  本实现取对称平方根作为规范选择 —— 这会让偏航有一个未知常数偏移，需要靠"对准已知方向"
  或转台实验消掉；
- 合成噪声下（acc 0.7 mg / mag 1 mG / gyr 0.03 dps RMS，按数据手册折算 + 0.5 dps 零偏）
  实测姿态误差 2~3°、yaw 抖动 σ≈2~3° → **增益仍需按真机数据标定**。

## 4. 与"参考包"的关系（许可与诚实性）

用户给的 `imu_code.zip` 里那份 MATLAB 是**纯开环积分**（无滤波、无磁、无 ZUPT，
"漂移补偿"是恒零空壳，且自写代码**无许可**）—— 见 `~/imu_code_考古报告.md`。
因此本实现：

- **算法取公开教科书内容**（Mahony et al., 2008 非线性互补滤波），**自写**，未复制任何
  第三方源码（参考包里的实现有 bug 且无许可，GPL 的那份也不能抄）；
- 单位换算直接用本项目驱动给的单位（mg / mdps / mG），**不沿用参考包里那套 MPU6050 口径常数**
  （8192 LSB/g、65.536 LSB/dps —— 那是 MPU6050 的，用在本机的 LSM6DS3 上会整体标错）；
- **dt 用真实测量值**，不用参考包的固定 1/200 s。
