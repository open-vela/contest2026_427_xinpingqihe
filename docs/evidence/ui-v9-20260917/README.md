### ② 单摆页截图：**连续 5 次重试仍 MISSING**（工具限制，非页面缺陷）

`pwshot` 抓帧要求"同一行两次读到相同内容"，而**单摆页是持续重绘的实时页**（曲线在跑），因此被行一致性校验拒绝 —— 这与早期 `sweep` 在实时页上失败是同一原因（见 `docs/10 §6.4`）。
**如实标注**：24 处强调条改动的**真机目视核对仍待补**；该改动是纯颜色替换（`X_ACC` → `pw_theme_accent()`），风险低，且同一强调色已在板块页（`06_board_s4_rows.png`）与主页（`03/04/05`）上目视确认过。
**补图方案（下轮）**：抓**静止页**（如 `about`）或用"进入页面前先暂停采样"的方式取帧。
