# 语音助手页 + 时间左移（2026-09-18，基于"重置前 UI"）

## 用户要求
1. 顶栏时间**左移一点点**；
2. 语音**应答**"你好，我是腕上物理工坊语音助手"。

## 实现
| 项 | 做法 |
|---|---|
| 时间 | `pw_topbar()` 计时标签 `LV_ALIGN_RIGHT_MID, -18 → -24` |
| 语音助手页 | 新增 `pw_voice_screen()`：标题"语音助手" + 卡片内三行文案（**应答句** / 可说的话 / 离线限制说明） |
| 入口 | 主页顶栏「…」左侧新增 **「语」** 按钮（56×44 触控区）→ 打开语音助手页 |
| 取证入口 | `phywear cap voice`（写入 `g_cap_seq` 之外，供 pwshot 单页抓取） |

## 如实说明（设备能力边界）
- MCU **没有离线中文 TTS** ⇒ 设备**不能真的"说出来"**；本页是**应答文案 + 入口**。
- **语音识别**同样需要 Agent 或网络链路（离线无 ASR）；页面内已如实标注"离线无语音识别：需 Agent 或网络"。
- 若后续要"真发声"，可行路线是：宿主机 TTS 生成 PCM → 转 16-bit/单声道 → 存 PSRAM/flash → 用板载扬声器（`/dev/spk0`）播放；需评估 flash/PSRAM 占用（一句 3 秒 16 kHz 单声道 ≈ 96 KB）。
