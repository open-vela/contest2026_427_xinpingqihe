## 1. Design Read（taste-skill §0.B 要求的一句话）

> Reading this as: 手持科学仪器 UI（导航 + 实时读数 + 图表）for 实验/课堂用户，
> with a **Swiss-Modernist 技术**语言，leaning toward `Swiss Modernism 2.0` + `Data-Dense Dashboard` on a `Dark Mode (OLED)` 基底。
> 随后按用户反馈两轮修正：**形态适配手表**（圆润 + 大字号）→ **风格来源换成穿戴向实名风格**；
> **去 AI 味**（删紫色渐晕、单一强调色）→ **补灵动**（数据/手指驱动）→ **少圆角** → **背景放开**。

旋钮（final）：`VARIANCE 4 / MOTION 4 / DENSITY 6`。

## 4. 四种页型（30+ 子页按此套用）

| 页型 | 覆盖页面 | 版式 |
|---|---|---|
| **① 实验读数页** | 单摆/弹簧/向心力/倾角/频谱/磁场频谱/轨迹/IMU | 页头 → **大数字 46px + 单位列** → 次级结果 → 曲线 → 参数步进（图标块 + −/＋）→ 取值芯片 → 主/次按钮 |
| **② 参数操作页** | 磁性标尺/秒表/光门/声门/音调 | 大计数居中 → 阈值步进 → 曲线 → 主/次按钮 |
| **③ 向导标定页** | 六面法/磁椭球/陀螺零偏/构建器 | 步骤圆点 → 大字指令 → 进度条 → 双按钮 |

右侧固定槽位 = 麦克风（`-20`），时间/版本/⋯ 让到 `-66`。

## 5. 交互与动效（全部非循环、由手指/数据驱动）

| 项 | 规则 |
|---|---|
| 按压 | scale .965 → 1.035 → 1（C3 过冲）+ 一次性强调色涟漪 |
| 入场 | 错峰 32–40ms，带轻微过冲 |
| 数值 | D1 脉冲（变化时闪一次，180ms）——**就是板上已实现的 `pw_motion_pulse_opa`** |
| 转场 | 共享元素展开（源矩形→目标矩形）/ 右拖返回（距离+速度判定 + 磁吸）/ 分页 = 圆点 + 液态拉伸 |
| 主题切换 | 全局 CSS 变量（板侧=同时改一组样式）+ 600ms 渐变 + 洗色遮罩（只动 opacity） |

## 6. 全局语音（用户明确要求：不做"主题页里的一个按钮"）

| 入口 | 行为 |
|---|---|
| **每页顶栏 🎙** | 按一下即唤起（全局，任意页面） |
| **始终聆听（开关）** | 开启后免按键；只对含唤醒词「手表/PhyWear」或明确指令动词的句子动作；麦克风角标小圆点指示 |
| **指令** | 切主题（玫瑰/青/琥珀/单色）· 打开某实验 · 回主页 · 打开设置 |
| **离线兜底** | Agent 不可用 → 长按弹出 **3–5 个指令芯片**（保证功能不丢） |

**设备现实**：无网络、无端侧 ASR 模型 ⇒ 真识别需 **Agent/宿主链路**；链路不通时降级为指令芯片。
始终聆听会持续占麦并增加功耗 ⇒ **默认关**，上板后实测待机电流与帧率再定。

## 7. 上板实现要点（避免"网页好看上板做不到"）

| 网页做法 | 设备做法 | 代价 |
|---|---|---|
| 底晕（2 段竖直渐变） | **LVGL 竖直 2 段渐变填充**（radius 0） | EPIC 直通，≈0 |
| 光流体（radial-gradient） | **预渲染光斑位图** 96×96 RGB565（PSRAM）+ 缩放/位移/透明度动画 | 一次 blit，不增 SRAM |
| 圆角 10/999 | 圆角≠0 会回退 CPU 光栅；P0 实测 14→0 **零 fps 增益**，故保留观感 | 已知、可接受 |
| 缩放（聚焦格 1.05） | LVGL 子件不随父缩放 ⇒ 降级为**框宽高 + 邻项降透明 + 描边** | 用户已确认 |
| 速度形变 skew | 降级为**强调条伸缩 + 卡片宽度微变** | 用户已确认 |
