# 12 · 动效 × 风格 整合方案（最终规划 · 待执行）

> **总目标**：**在帧率不变的前提下，营造"高级感"**。
> **硬约束（违反即回滚）**：单次动效 **≤320 ms**、只改**几何(x/y/w/h)或不透明度**、**不循环**、**同屏并发 ≤1**、
> 不碰 EPIC 三禁区（圆角 / 阴影模糊 / transform 缩放旋转）。
> **验收判据**：同口径 `[PERF]` + 30 s 心跳，改动前后 **fps 与 loops 不降**（允许 ±1）；动效期间单帧窗口 **≤17.5 ms**。
> **数据来源**：用户提供的上游 main 分支 zip（已全量入库 `third_party/ui-ux-pro-max/`，2.6 MB，MIT）。

## 2. 动效体系（上游 `motion.csv` → 本板翻译）

### 2.1 触发方式翻译（本板**没有 hover / scroll / 鼠标**）

| 上游触发 | 本板等价触发 | 说明 |
|---|---|---|
| `hover` | **press（手指按下）** | 按下即给反馈，抬起回位 |
| `scroll (viewport enter)` | **页面 / 子页进入** | 打开时内容入场 |
| `load or scroll`（stagger） | **宫格 / 列表入场** | 逐块错峰 |
| `route change` | **屏幕切换（只动内容层）** | 不做整屏转场（整屏重绘成本高） |
| `on mount / async wait` | **进度反馈** | 计数/进度条淡入，一次性不循环 |
| `scroll (continuous)` / `timer auto-rotation` | ❌ **裁掉** | 无滚动、无轮播；且本板**禁止循环动画** |

### 2.2 曲线档位（上游 easing → 本队查表曲线）

| 上游 easing | 本板曲线档 | 参数 | 过冲 | 典型场景 |
|---|---|---|---|---|
| `power1.out` / `power2.out` | **C1 `settle`** | 临界阻尼 ζ=0.70 | 无 | 按压回位、数值更新、进度淡入 |
| `back.out(1.4)` | **C2 `soft`** | ζ≈0.45 | ~20% | 卡片/宫格入场（＝现有 spring 档） |
| `elastic.out(1,0.4)` | **C3 `bounce`** | ζ≈0.25 | ~45% | 「归零」等**明确操作**的回弹 |
| `expo.out` | **C4 `snap`** | ζ=0.90，短时长 | 无 | 即时反馈（图标/状态点） |
| `sine.inOut` | **D1 `pulse`** | 现有 decay（a=6, f=2） | 对称振荡 | 提示脉冲（一次性） |

> 实现：扩展现有 `tools/phywear/gen_motion_table.py` 输出 4 条 spring + 1 条 decay（每条 129 点 × Q14 = 258 B），
> **flash 约 1.3 KB**（现有 516 B → +780 B）；`pw_motion` 增加"按档取曲线"的 API，解析式实现继续保留作对照与回退。

### 2.3 时长规范（取自上游，按本板收敛到硬顶 320 ms）

| 场景 | 上游 | 本板取值 |
|---|---|---|
| 按压反馈 | 150–200 ms（Subtle） | **150 ms** |
| 内容入场 | 300–400 ms（Subtle） | **300 ms** |
| 宫格错峰 | 250–350 ms（Subtle） | 单块 **280 ms**，起始错峰 **+50 ms/块**（最多 5 块） |
| 明确操作回弹 | 200–300 ms（Standard） | **320 ms（硬顶）** |
| 进度反馈 | 800–1600 ms | 不循环，**进度变化时淡入 150 ms** |

### 2.4 接入点清单（8 处，分两批）

**批 1（低风险，先做，逐处出真机截图）**
1. **主页 tile 按压**：按下 y+2 px、卡片色变 `PW_COL_CARD_LT`，抬起 C4 回位（**不用 scale**）
2. **工具板进入**：8 个子项以 C2 依次滑入（y+10 px → 0）
3. **轨迹页「归零」按钮**：点击后 C3 轻微回弹（y±3 px，一次性）
4. **标定完成状态点**：`decay` 脉冲一次（透明度 100%→40%→100%，**不循环**）

**批 2（页面级）**
5. 读数页数值更新：C1 淡入 150 ms（仅当数值真的变化时触发）
6. 图表页首次绘制：C2 整体滑入 300 ms
7. 向导页步骤点：切步时 C1 过场 150 ms
8. 秒表开始/停止按钮：C4 snap 150 ms

### 2.5 预算、开关与验收

- 总开关 **`PW_UI_MOTION`**（0 = 全关回到现状；1 = 开），另有**每处独立宏**（如 `PW_MOTION_HOME_PRESS`）
- 代码内硬约束：`dur ≤ 320 ms`、非循环、单对象；同一屏同一时刻只允许 1 个动画在跑
- 验收：改前/改后同口径 `[PERF]`（每秒一行）+ 30 s 心跳各 2 次；**fps/loops 不降**且动效期间单帧窗口 ≤17.5 ms
- 截图存档：`docs/evidence/ui-motion-<date>/`

## 3. 风格体系（页面类型 → 风格档 → 色板 → 字号 → 密度）

| 页面类型 | 上游风格（实名） | 取什么 / 砍什么 | 色板 | 字号层级 | 密度 |
|---|---|---|---|---|---|
| 主页入口宫格 | **Bento Box Grid** + **Flat Design** | 取"不同尺寸直角卡片拼贴"；砍 rounded-xl / shadows / hover-scale | `colors.csv` 取 Dashboard 类 | 标题 LARGE(24) / tile 名 MED(20) / 说明 BODY(14) | 2×4 宫格 |
