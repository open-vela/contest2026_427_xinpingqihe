## 3. 力学实验

| 实验 | 原理与算法 | 端侧实现 | 实测 |
|---|---|---|---|
| 单摆测 g | 自相关测周期 T → `g = 4π²L/T²` | `pw_analysis` 自相关 + `phywear_pend.c` | **真机 g 误差约 1.8%**（2026-09-12 记录） |
| 弹簧振子 | 峰值/过零检测周期、相对振幅 | `phywear_spring.c` | 界面与串口输出可用 |
| 向心加速度 | `a = r·ω²` 最小二乘拟合斜率求 r | `phywear_centri.c` | 界面与串口输出可用 |
| 弹性碰撞能量损耗 | — | 【未实现，规划中】 | — |

所有算法**端侧完成、不依赖手机**；单摆/弹簧/向心另有文本子命令（`phywear pendulum|spring|centripetal`）经 UART 输出结论。

## 4. 声学（2026-09-13 补全）

| 能力 | 实现 | 真机实测 |
|---|---|---|
| 麦克风频谱（FFT） | `pw_spec_mic_screen` + radix-2 FFT | 界面可用（依赖 `/dev/mic0`） |
| **扬声器发声** | 板级驱动 `sf32lb52_spk.c/.h`：AUDCODEC DAC0 + DMA2_Channel1 循环播放 + 功放使能脚 PA42；字符设备 `/dev/spk0`，ioctl：`TONE/STOP/VOLUME/PA`；Kconfig `CONFIG_SF32LB52_SPK`；默认音量 +12 dB | ✅ **连续播放 440/660/880/1760/220 Hz 五段全部成功**；人耳确认可听到 |
| **音频发生器页面** | `phywear_tone.c`：频率 40 Hz–4 kHz（−/+ 20 Hz 步进 + 220/440/880/1760 预设）、音量 −36~+30 dB、播放/停止、离开页面自动停声 | ✅ 真机截图渲染正常（`tone.png`） |
| **麦克风采集** | 增益 0 → **+30 dB**（`sf32lb52_mic.c`） | ✅ 0 dB 时静音/大声都只有 15~40 LSB；+30 dB 后环境噪声 ≈570 LSB。⚠️ **同板喇叭→麦克风的空气耦合很弱**：放 1 kHz 正弦时最高测到 12,000 LSB（−8.4 dBFS，需贴近/最大音量），常规音量下与环境噪声同量级；低频（如 90 Hz）拾到的多是二次谐波与环境隆隆声 → **不能用"喇叭当已知声源校准频谱"**，属物理限制（见 `06_真机验证记录.md` §3.3） |
| 命令行自检 | `phywear tone <Hz> [ms] [dB]`、`phywear micread [n]`（打印 peak/dBFS/rms） | ✅ |
| 频率追踪 / 多普勒 / 声呐 | — | 【未实现，规划中】 |

|---|---|---|---|
| 启动随机卡死（镜像微变即复现，只打印 `AB` 或 `ABCD`） | 逐段插桩（`arm_lowputc`）定位到 `BSP_Board_PreInit` 内**时钟/晶振建立时序竞争** | XTAL32 起振、DLL1 锁定（切 240 MHz 系统时钟前）、DLL2 锁定（切 FLASH2 XIP 时钟前）三处各补 2 ms；PSRAM 通路在 1.8V LDO 使能后补 2 ms | **连续 5/5、6/6 复位启动正常**（含 2.02 MB 全功能镜像）；修复前镜像稳定复现卡死 |
| 主动场景导致 GUI 卡死 | Agent 工具与 GUI 抢 IMU + 抢切页（跨任务 fd 无效） | 主动推送默认关闭（见 §7） | 150 s 泡机：心跳 t=30/60/90/120/150 s 连续、摆动事件触发 2 次均只记日志、界面不卡 |
| 扬声器只能响第一段 | 应用侧缓存的 fd 跨进程失效（EBADF） | 每次调用重新 open/close；驱动侧 DMA 常驻循环（避免反复 Start/Abort 返回 HAL_BUSY） | 连续 5 段不同频率全部 ok |
| 顺带省 flash | — | 关闭未使用的 `CONFIG_EXAMPLES_LVGLDEMO`（−300 KB） | 固件 2.02 MB（原 2.17 MB） |

**已排除项**（都做过对照实验，避免误判）：ftab 分区窗口、`.data/.ramfunc` 加载地址越界、
flash 烧写不完整（前 512 KB 逐块读回逐字节一致）、扬声器驱动本身。

## 10. 已知限制（汇总，如实）

1. **主动场景默认关闭**：摆动检测可用但不自动触发 Agent（原因见 §7）；无障碍播报、开机语音引导、结果语音播报均为规划中。
2. **真机无网络栈**：无 WiFi/BLE 协议栈镜像，真机上的 LLM 对话不可用；LLM 侧在模拟器验证。
3. **语音交互**（唤醒词 / ASR / TTS）：【未实现，规划中】。
4. **声学未完成项**：频率追踪、多普勒、声呐【未实现】。
5. **力学未完成项**：弹性碰撞能量损耗【未实现】。
6. **自定义实验构建器、AI 教练页**：入口灰显【未实现，规划中】。
7. **传感器原始日志流导出**【未实现，规划中】（结果目前经 UART 文本或界面读取）。
8. **模拟器限制**（非功能缺陷）：窗口黑屏（qemu goldfish 只合成 GPU 层，LVGL 绘制在 `/dev/fb0`，视觉验收以读 fb 截屏为准）；每启动仅首个进程能渲染，逐页截图需重启；无 `/dev/mic0` 时声学页报错退出。
9. **演示视频尚未录制**（≤5 分钟）；作品展示照片待补。
10. **端侧 AI 硬件产品创新**：属规划方向，本作当前核心成就在"新硬件平台适配"。
