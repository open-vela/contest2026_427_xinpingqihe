v3.1 改了什么 / 为什么

你提的问题v3.1 的做法依据
8 个模块要一屏可点 主页改回 8 格一屏，但保留"聚焦"语言：按住并滑过任意格 → 该格点亮放大（web 真缩放；上板降级为框宽高+描边+邻项降透明）、 顶部信息条实时显示它的名称/说明/规模、下方 8 槽液态指示器同步；抬起才进入。 你的要求"一次性能按到全部 8 大模块"，同时保留卡片流的"有当前项、有方向、有磁吸"
板块页太丑 重做：hero 区（模块色渐晕 + 图标块 + 26px 标题 + 说明 + 规模胶囊）、行内加 序号 / 3px 强调轨 / 名称+元信息 /「开始」胶囊； 规划项整行弱化 +「规划中」胶囊；底部"右拖返回"提示。 原版行只有名称 + 一行灰字，缺层级、缺信息、缺质感
中心聚焦降级已确认：不做真缩放 → 框宽高 + 邻项降透明 + 描边/底纹LVGL 子件不随父缩放
速度形变降级已确认：不做 skew/scale → 强调条按速度伸缩 + 卡片宽度微变；本原型只用在读数页翻页文字不可 skew

8 种质感动效：本原型用到 6 种

效果用在哪关键规则上板可行性
中心聚焦主页"指下聚焦"按到哪个格哪个格点亮；视觉焦点 ≠ 业务选择，抬起才提交★★☆ 降级：框宽高+描边+邻项透明
磁吸吸引聚焦吸附到格子；右拖返回的落点进入范围后越近吸得越明显，边缘不突跳；拖动中保留控制感★★★ 纯位移混合
液态指示器主页 8 槽 + 读数页 6 页先拉长再收拢；连续切换从当前形态接续，跟随最后一次选择★★★ left/width + 圆角
共享元素展开格子 → 板块页；迷你图 → 全屏图源/目标矩形对应；关闭回到仍存在的源；文字不跟着拉伸★★★ 一个矩形动几何
手势转场板块页右拖返回；读数页翻页位移映射进度；松手按距离+速度决定完成/取消；保留返回按钮★★★ 纯几何
速度形变读数页快速翻页速度=位置差÷时间差并平滑；有上限；停手恢复；正文可读★★☆ 降级：强调条伸缩
3D 视差 / 碰撞推挤✗ 仍不选：手表无指针（视差只能靠姿态传感器，会与手势抢）；界面无自由浮动元素（碰撞属纯装饰）
请重点看这两处：
① 主页按住滑动时——聚焦是否跟手、信息条与指示器换得是否顺、抬起进入是否自然；
② 板块页 hero + 行卡片的新版式是否够好看（上一版最丑的就是这里）。

你点头后：先上板做主页 + 板块页两屏真机验证（同口径帧率 A/B、SRAM 核对、真机截图），再铺读数页与其余页面。
