主题页 + Agent 语音切换 + 渐变 新增主题与布局页：4 套主题（玫瑰/青/琥珀/单色）列表 + 主页布局切换 + Agent 语音入口。 切换不是瞬间：所有颜色走 CSS 变量，全局 transition .6s；再叠一层强调色"洗色"遮罩（只动 opacity，符合 §6.A）。 点麦克风会模拟一轮语音：聆听 → 识别"切换青色主题" → 渐变切换 + 顶部提示条。
