taste-skill 的硬规则：上一版为什么"太AI"，这版怎么改

规则上一版（v3.1）v4
§0.D 反默认
+ §4.2 LILA 规则		 紫色渐晕 hero（AI-purple gradient 默认货）+ 8 个彩色强调色 删掉所有装饰渐变；全局 1 个强调色 Emerald #22C55E；模块身份改用「序号 + 名称 + 元信息」
§4.2 调色板锁定每块一个色，色彩在页面间漂移 锁定单一强调色；唯一文档化例外：曲线通道色（X/Y/Z）只用于数据标记，不进 UI chrome
§4.4 形状锁定圆角卡片 + 圆形点 + 胶囊按钮混搭 圆角一律 0：状态点、分页指示都做成矩形段；同时是 EPIC 直通路径（radius 0）
§4.4 卡片克制什么都是圆角卡片 + 彩色底 用 1px 细线 + 间距分组；#121212 填充只用于"聚焦/按下"这一层真实层级
§6.A 只动 transform/opacity分页器动 left/width 分页段用 transform: scaleX；共享元素用 translate+scale（初始尺寸定死，只动 transform）
§5.D / §6.B无 reduced-motion 处理 无滚动监听/常驻 rAF；prefers-reduced-motion: reduce 时全部退化为瞬时切换
§4.1 字体默认无衬线堆叠、数据不做等宽对齐 grotesque + mono 数据（本机取 DejaVu Sans / DejaVu Sans Mono；上板用位图字体，计划加一套「数字等宽」子集）
选型仍保留的 6 种质感动效（用户已确认的降级不变）：中心聚焦（改为 scale+填充+强调轨）、磁吸吸附、 液态指示器（改为 scaleX 拉伸，形状仍是矩形）、共享元素展开、手势转场、速度形变（强调轨伸缩）。
3D 视差 / 碰撞推挤仍不选（手表无指针；界面无自由浮动元素）。

请重点看：① 这个"纯黑 + 单强调色 + 零圆角 + 细线分组"的仪器气质对不对路； ② 主页一屏 8 格是否仍然一眼可点；③ 读数页的大数字对齐与密度。
