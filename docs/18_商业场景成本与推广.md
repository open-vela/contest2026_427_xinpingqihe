## 1) 应用场景

- **校内教学**（初中/高中物理、科学课后服务）：基础器材已普及 —— 2024 年初中理科实验仪器配备达标率 **97.54%**、普通高中 **96.76%**（教育部《2024 年全国教育事业发展统计公报》），增量只剩**探究性/数字化**实验；实验操作已纳入中考、经费须从生均公用经费列支（教基〔2019〕16号）。障碍：现行装备配置标准中**无「腕上多传感器实验设备」品类**（推测），且校内单价低（山东课后服务每生每课时 ≤3.5 元）。
- **科普研学**（科技馆、研学机构、馆校合作）：痛点是缺**可穿戴、可走动演示**的量化实验教具。基础：2023 年全国科普经费 **215.06 亿元**、政府拨款占 **77.7%**（科技部）；免费开放科技馆 **409 座**，2024 年联合行动联动 **3625 所**中小学、服务 **7218.98 万人次**（中国科技馆）；研学游市场 **2132 亿元**、同比 +19.04%（艾媒咨询 2025，第三方测算）。
- **家庭与个人**：痛点是 **phyphox 手机 App 免费**（RWTH 亚琛开源项目）已形成极低价锚点；家庭决策首看安全 34.21%、行程 33.13%、教育内容仅 32.51%（艾媒咨询 2025）。

**最可能率先落地：科普研学 / 馆校合作** —— 有财政科普预算与现成客流、**不依赖政府采购目录**、决策链短、可小批量试点；校内需先解决品类与目录问题，家庭端直面免费替代。

# 6) 成本参数化模型（2026-11-04 补，全部参数标注假设）

> 本节与 §2 的关系：§2 给的是「按公开行情估的区间」，本节给的是**公式与敏感性**——即"当 BOM 落在哪一档时，哪种定价会亏"。所有 `【假设】` 均为待验证参数，**不是报价**；能与 §2 区间对上的地方已注明。

## 6.1 单台成本公式

```
C_unit = C_board + C_screen + C_battery + C_shell + C_assembly + C_packaging + C_loss
```

21 个未知量按七项拆开（每项 3 个）：主板单价 / 版型差价 / 来料不良率；屏单价 / 贴合排线 / 破损率；电芯单价 / 保护板点焊 / 认证摊销（UN38.3、IEC 62133 均未做）；模具摊销 / 单件加工 / 结构辅料；组装工时 / 工时费率 / 校准测试直通率；彩盒内衬 / 附件 / 说明书；生产损耗 / 售后返修 / 库存跌价。**逐项填写要求见 §9 的「BOM 实价化」**。

简化：`C_unit = X × (1 + m)`，`X` = BOM，`【假设】m = 0.20`。

## 6.2 表一：成本加成定价（`【假设】k = 2.5`，`Y = kX`）

| BOM X（元） | 非物料 m·X | 总成本 1.2X | 售价 2.5X | 单台毛利 | 毛利率 |
|---:|---:|---:|---:|---:|---:|
| **150** `【假设档位】` | 30 | 180 | 375 | 195 | 52.0% |
| **250** `【假设档位】` | 50 | 300 | 625 | 325 | 52.0% |
| **400** `【假设档位】` | 80 | 480 | 1000 | 520 | 52.0% |

**结构性结论**：倍率定价下 `Z = (k − 1.2)/k`，**毛利率与 X 无关**——倍率只是把成本风险原样转嫁给售价，本身不构成竞争力。

## 6.3 表二：市场锚定定价（售价由外部决定，成本自己扛）

| BOM X | 总成本 | Y=399 `【假设】` | Y=599 `【假设】` | Y=899 `【假设】` |
|---:|---:|---:|---:|---:|
| **150** | 180 | 54.9% | 70.0% | 80.0% |
| **250** | 300 | 24.8% | 49.9% | 66.6% |
| **400** | 480 | **−20.3%（亏）** | 19.9% | 46.6% |

**盈亏平衡 BOM**：`X* = Y/1.2` → Y=399 时 `X*≈332.5`；Y=599 时 `≈499`；Y=899 时 `≈749`。**读法**：BOM 一旦落到 400 元档，399 元定价在公式上就是亏的——这是必须先做 BOM 实价化的原因。与 §2 的「千级 BOM ≈ ¥100–155/台（估计）」对得上：落在 150 档，399 元定价安全。
