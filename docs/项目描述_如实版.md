**项目名称**：openvela腕上智慧物理工坊(PhyWear)

**一句话定位**：基于立创黄山派开发板，将手机物理工坊（phyphox）的核心功能移植到手表端，打造集传感器数据采集、物理实验与腕上智能工具于一体的可穿戴设备。

**目标开发板**：立创黄山派（SF32LB52-MOD-1）

**选板理由**：板载六轴IMU、三轴地磁传感器、环境光传感器及麦克风等丰富传感器，完美适配物理实验需求；获openvela官方支持，超低功耗适合可穿戴场景。


**核心功能（按实际实现，如实标注）**：

传感器原始数据采集与实时显示（加速度、陀螺仪、磁力计、环境光），所需硬件能力：六轴IMU、三轴地磁传感器、环境光传感器【已实现】
力学实验（向心加速度测量、"摆"测重力加速度g、弹簧振子频率分析），所需硬件能力：六轴IMU【已实现；注：弹性碰撞能量损耗未实现】
声学实验（声音频谱分析），所需硬件能力：板载MEMS麦克风【已实现；注：历史频率追踪、音频发生器、多普勒效应测试未实现，需喇叭硬件】
工具类功能（加速度频谱、斜面倾角测量、磁性标尺、磁场频谱），所需硬件能力：六轴IMU、三轴地磁传感器【已实现】
计时器功能（运动秒表、光学秒表、声学秒表），所需硬件能力：六轴IMU、环境光传感器【已实现】
AI Agent主动交互（运动模式识别、主动弹出实验建议、语音快捷启动），所需硬件能力：六轴IMU、麦克风、8MB PSRAM【未实现，规划中】


**各功能技术方案**：

1. 传感器数据采集：基于适配好的IMU、地磁、环境光驱动，通过I2C/SPI接口读取原始数据，在1.85寸AMOLED屏幕上实时显示各传感器数值与波形。【已实现】
2. 力学实验：基于加速度计和陀螺仪数据，在手表端完成向心加速度换算、摆模型拟合重力加速度、FFT频率分析、峰值检测等算法。【已实现；能量损耗计算未实现】
3. 声学实验：基于MEMS麦克风采集音频，利用FFT实现频谱显示，自相关算法测单音频率。【已实现；PWM驱动喇叭输出指定频率音调未实现，需喇叭硬件】
4. 工具与计时器：加速度FFT频域分析；加速度三轴分量计算斜面倾角；地磁传感器检测磁铁间距；环境光传感器检测遮光触发计时；加速度计检测运动事件触发计时。【已实现】
5. AI Agent主动交互：基于openvela ai_agent框架，实时分析IMU数据流，识别摆臂、跑步、久坐、异常噪音等事件并主动推送实验建议，支持语音快捷启动。【未实现，规划中】
6. 腕上UI设计：基于LVGL适配1.85寸AMOLED，操作路径控制在3步以内，关键数据以大字体卡片呈现。【已实现；全中文界面】
7. 独立运行与数据导出：所有算法在手表端完成，不依赖手机；摆测g、弹簧、向心等实验的分析结果通过UART串口打印，供物理实测读数。【已实现；"传感器原始日志流导出"未实现，规划中】

## 关于本描述的出处与可核实性

- 上述"已实现"各功能，均有对应的**真实源码**（`app/phywear/*.c` 的 `pw_*_screen()` 构造函数、
  `src/nuttx/drivers/sensors/` 传感器驱动）与**中文界面截图**（`docs/evidence/`）佐证。
- **归属说明（如实）**：**EPIC 硬件加速后端来自官方 PR**（vendor_sifli #31 / apps_graphics_lvgl #41 /
  nuttx-apps #121），**非本队自研**；本队在其基础上集成，并做传感器驱动、触控修复、PhyWear 应用与
  UI/算法层优化。
- **性能说明（如实）**：**43 FPS 为真机（SF32LB52）成绩**（官方 EPIC 硬件加速 + 本队 UI/算法层
  优化）；模拟器（goldfish，无 EPIC 硬件）经 UI/算法层优化为 **22–23 FPS**。即 43 FPS 需真机硬件
  + 官方 EPIC 后端，模拟器不可复现。
- "未实现"部分（AI 交互 / 弹性碰撞 / 历史频率 / 音频发生器 / 多普勒 / 传感器日志流导出），
  在源码中**确无对应实现**，且已列入作品 README 第八节"已知限制"如实标注。
- 各功能的详细实现清单与来源，见 `app/phywear/NOTICE.md`、`src/MANIFEST.md` 与 README。
